Overview

BiNeuron is the main class of the biNeuron package. It orchestrates the entire workflow: language detection, model selection, download & caching, prompt engineering, AI inference, file editing, and interactive chat.

Language Detection

Detects programming language(s) from requests and attached files using heuristics or AI.

Adaptive Model Selection

Automatically picks the best GGUF model based on language and your hardware.

File Editing

Optional two-stage pipeline: AI generates code, then a lightweight model applies whole-file replacements.

Prompt Guidelines

To get the best results from the AI, follow these core principles.

  • —
    Use English when possible — most models are trained primarily on English data.
  • —
    Specify programming languages explicitly — e.g. “Python 3.11” not just “code”.
  • —
    Provide detailed task descriptions — include inputs, outputs, edge cases, and constraints.
  • —
    List your technology stack — frameworks, libraries, and versions.
Weak prompt
“Write code for a web scraper.”
Strong prompt
“Develop a Python 3.11 script using BeautifulSoup 4 and Requests 2.31 that scrapes product names and prices from https://example.com/products. The script should accept a URL as a command‑line argument, output results as a CSV file with columns ‘name’ and ‘price’, and handle pagination by following ‘Next’ links. Include error handling for network timeouts and missing elements.”

Final tips: Be concise but complete, use bullet points for complex requirements, specify output format, and mention constraints (e.g., “must run on Windows”).

Рекомендации по промптам

Чтобы получить наилучшие результаты от ИИ, следуйте этим основным принципам.

  • —
    По возможности используйте английский — большинство моделей обучены преимущественно на английских данных.
  • —
    Чётко указывайте языки программирования — например, «Python 3.11», а не просто «код».
  • —
    Давайте подробное описание задачи — включайте входы, выходы, краевые случаи и ограничения.
  • —
    Перечисляйте технологический стек — фреймворки, библиотеки и версии.
Слабый запрос
«Напишите код для веб-скрапера.»
Сильный запрос
«Разработайте скрипт на Python 3.11 с использованием BeautifulSoup 4 и Requests 2.31, который собирает названия товаров и цены с https://example.com/products. Скрипт должен принимать URL как аргумент командной строки, выводить результаты в CSV-файл с колонками "name" и "price" и обрабатывать пагинацию, переходя по ссылкам "Next". Включите обработку ошибок для сетевых тайм-аутов и отсутствующих элементов.»

Заключительные советы: Будьте кратки, но полны, используйте маркированные списки для сложных требований, указывайте формат вывода и упоминайте ограничения (например, «должен работать в Windows»).

概述

BiNeuron 是 biNeuron 包的主类。 它协调整个工作流程：语言检测、模型选择、下载与缓存、提示词工程、 AI 推理、文件编辑和交互式聊天。

语言检测

从用户请求和附加文件中确定编程语言，使用启发式或 AI。

自适应模型选择

根据检测到的语言和硬件自动选择最合适的 GGUF 模型。

文件编辑

可选的两阶段流水线：AI 生成代码，轻量级模型应用整文件替换。

提示词指南

要获得最佳 AI 响应，请遵循以下核心原则。

  • —
    尽可能使用英语 — 大多数模型主要基于英语数据训练。
  • —
    明确指定编程语言 — 例如“Python 3.11”，而不仅仅是“代码”。
  • —
    提供详细的任务描述 — 包括输入、输出、边缘情况和约束。
  • —
    列出技术栈 — 框架、库和版本。
弱提示词
“为网页爬虫编写代码。”
强提示词
“开发一个 Python 3.11 脚本，使用 BeautifulSoup 4 和 Requests 2.31，从 https://example.com/products 抓取产品名称和价格。脚本应接受 URL 作为命令行参数，将结果输出为包含 ‘name’ 和 ‘price’ 列的 CSV 文件，并通过跟随 ‘Next’ 链接处理分页。包括对网络超时和缺失元素的错误处理。”

最后建议： 简洁而完整，对复杂要求使用项目符号，指定输出格式，并提及约束（例如“必须在 Windows 上运行”）。
